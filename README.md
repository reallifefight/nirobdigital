## 📖 Overview

Nirob Digital is a **production‑ready static website** that serves as a knowledge base and income‑generating platform. It covers trending tech topics (AI, Linux, Android, Crypto, SEO, Blogging) and integrates **Google AdSense** and **affiliate marketing** from day one.

The site is built with **pure HTML5, CSS3, and vanilla JavaScript** – no frameworks, no dependencies. It works flawlessly on any hosting (cPanel, GitHub Pages, Netlify, etc.) and is optimized for speed, accessibility, and search engines.

---

## ✨ Features

### 🎨 Design & UX
- **Glassmorphism UI** with translucent cards, backdrop blur, and neon gradients.
- **Dark / Light mode toggle** (stored in `localStorage`).
- **Mobile‑first responsive** – hamburger menu on small screens.
- **Smooth animations** – card hover lift, button neon glow, back‑to‑top button.
- **Cookie consent banner** (GDPR friendly).

### 📈 Monetization Ready
- **Google AdSense** ad unit (`ca-pub-5978347024657367`) embedded on every page.
- **Affiliate disclosure page** listing partners: Binance, RedotPay, CWallet, Kit.
- **SEO optimised** for high‑RPM niches (AI, crypto, finance, hosting).
- **Affiliate links** naturally inserted into relevant articles.

### ⚡ Technical
- **44 interconnected pages** – all with unique `<title>`, `<meta description>`, and `<meta keywords>`.
- **Clean URLs** (no `.html`) via `.htaccess` rewrite rules.
- **Client‑side search** powered by `search.json`.
- **Category & tag pages** that dynamically pull articles.
- **Interactive tools** (password generator, SEO preview, crypto calculator, IP lookup).
- **Open Graph & Twitter Card** meta tags for every page.
- **JSON‑LD structured data** (Organization, Article, FAQ, Breadcrumb).
- **Sitemap.xml**, **robots.txt**, **ads.txt** included.
- **404 error page** with custom design.
